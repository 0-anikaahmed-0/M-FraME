# M-FraME
M-FraME: a multilingual benchmark testing whether LLMs can be jailbroken into giving unlicensed medical advice. 100 patient queries × 6 framings (direct, indirect, emotional, hypothetical, random/assigned role-play) × 4 languages (English, Bangla, Hindi, Urdu) = 2,400 prompts across 4 medical topics.
